# BURN

BURN is the evaluation phase. It runs after completing work, not during it.

## Files

- **evaluate-against-goals.md** — Assess how well you met the user's goals, plus any standing goals in CLAUDE.md or goals/. Be honest about gaps.
- **route-improvements.md** — Take the insight from evaluation and route it: wisp if the thought is incomplete, wow if it is a solid reusable ability, cow if it is about context or known state.

## Working here

BURN is not optional. Every non-trivial task should end here. The evaluate → route sequence is the mechanism by which the system improves over time — skipping it means insights are lost.

Do not rush BURN. A weak evaluation produces weak wisps and wows.
