# CHURN

CHURN is the active-work phase. These blocks govern how to behave while executing a user-requested action.

## Files

- **use-wows-and-cows.md** — Before acting, consult ways-of-working and context-wayfinding. Let existing knowledge shape your approach rather than starting from scratch.
- **cache-in-cows.md** — Write fetched or generated data to context-wayfinding/cache/ with a proper attribution header (source, model, datetime, stale-after).
- **track-progress-in-efforts.md** — Keep an effort file updated in efforts/ for any non-trivial task. Do not wait until the end.
- **no-wisps-during-churn.md** — Do not read wisps while working. They are unvalidated and can corrupt reasoning at decision time.

## Working here

Read all four blocks at the start of any non-trivial task. The order matters: orient first (use-wows-and-cows), then set up your working state (cache, efforts), and keep the no-wisps constraint active throughout.
